# Fake Test Plan

## Goal

Exercise the edit, plan-file, and draft PR workflow without changing product behavior.

## Steps

1. Add a small test edit.
2. Add this fake plan under `plans/`.
3. Open a draft PR for review.

## Exit Criteria

- A harmless test edit exists in the branch.
- A fake plan file exists under `plans/`.
- A draft PR is created from this branch.

## Validation

No behavior validation is required because this is an intentional no-op workflow test.
