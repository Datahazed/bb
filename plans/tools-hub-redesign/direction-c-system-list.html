# Deep Research

A harness for multi-source, fact-checked research. Fan out web searches, fetch sources, adversarially verify claims, then synthesize a cited report.

## When to use

When the user wants a deep, multi-source report. If the question is underspecified, ask 2–3 clarifying questions first, then weave the answers into the query.
